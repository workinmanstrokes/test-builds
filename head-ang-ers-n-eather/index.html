🔊 Soundboard

Tap a pad, get the laugh in under ten seconds.

🔈 Speaker-only playback — sound comes out of this device's speakers. See the Routing guide below to send it to OBS or Discord.

Keyboard: keys 1–0 and Q–Y play pads 1–16, Esc stops all.

🔍 Search sound effects

Live search of the Internet Archive. Preview, then one tap saves it to the board.

🎙️ Recorder

Record your own sound, save it to a pad, and it replays after reload. Recordings stop automatically at 60 seconds so they fit on-device storage. Needs mic permission — if this browser has no mic support, Record is disabled with an explanation.

✏️ Pad editor

Tap a pad below to select it, then rename it, download its sound, or delete it.

⛓️ Macro builder

Chain up to 8 pads into one tap: arm chain-building, tap pads in order, name it, save. Saved macros play their steps in order (each step waits for the previous sound, at least 250 ms apart); delete a macro with its ✕ button.

📡 Routing guide — OBS / Discord

Status: speaker-only playback is the default. Sounds play through this device's speakers. To route them into a stream or a call, use one of these setups — neither is verified yet on a live stream. Verification checklist (OBS meter moves, Discord hears the pad) is in TESTING.md — run it before telling anyone routing works.

OBS browser source (recommended first)

  1. Host this board on a URL OBS can reach (or serve it locally and use that address).
  2. In OBS: Sources → + → Browser → create new, paste the board URL, set width 800 × height 600.
  3. Tick “Control audio via OBS” so the browser source audio goes to the stream mix, not just your speakers.
  4. Tap a pad and confirm the OBS audio meter moves. If it does not, un-tick and re-tick the audio control, then restart the source.

Discord / virtual cable (desktop)

  1. Install a virtual audio cable (e.g. VB-Cable) and set it as this browser's output device.
  2. In Discord, set the virtual cable as your microphone input (or use it as a mic in OBS).
  3. Tap a pad — listeners hear it as your mic. Keep the volume low to avoid clipping.
